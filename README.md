# **Just Create**

Minecraft modpack based on "Create" mod

## What is it for?
Really simple and clean modpack with mostly create and farmers delight  
Made for people who want minimal create modpack or a good base to start building own modpack  

## Server
Pakku also exports a server version. You can install it under [github releases](https://github.com/mafien0/just-create/releases/latest)
